External Purchase Link entitlement — это официальное разрешение от Apple: в приложении можно показать кнопку/ссылку «оформить на сайте» для цифровой подписки, и пользователь уйдёт в Safari на ваш checkout (ЮKassa), а не в In‑App Purchase.

Это не «просто открыть URL» — нужно пройти процедуру и использовать StoreKit API.

Как это работает по шагам
1. Запросить entitlement у Apple
В App Store Connect / через форму Apple запрашиваете com.apple.developer.storekit.external-purchase-link для вашего bundle ID.
Для России (ru) Apple это предусматривает, но форма иногда падает с ошибкой — тогда пишут в Developer Support.

2. Подключить в Xcode
В .entitlements добавляется ключ:

<key>com.apple.developer.storekit.external-purchase-link</key>
<true/>
3. Указать URL оплаты в Info.plist
Для storefront ru — ссылка на страницу подписки на сайте, например https://zerosmoker.ru/subscribe.

4. В коде — StoreKit API, не просто launchUrl
Перед переходом вызываете API External Purchase Link:

проверяете, доступна ли внешняя оплата (canOpen);
Apple показывает системный экран: «Вы переходите на внешний сайт, Apple не отвечает за покупку там»;
только после этого открывается Safari с вашим checkout.
5. На сайте — ЮKassa
Пользователь платит на сайте; бэкенд помечает подписку активной; в приложении после логина подтягивается статус.

6. Отчётность Apple (в ряде регионов)
В EU и иногда в других зонах — комиссии/отчёты по внешним покупкам. Для RU уточняют в addendum при одобрении entitlement.

Чем это отличается от «просто перекинуть на сайт»
Без entitlement	С entitlement
Кнопка «Купить на сайте» → реджект 3.1.1
Кнопка через StoreKit → допустимо
Свой WebView с оплатой → реджект
Safari + disclosure sheet → ок
Намёки «на сайте дешевле» → риск
Можно объяснять подписку на сайте (в рамках правил)
Что это значит для ZeroSmoke
Подать заявку на External Purchase Link для bundle ID (RU storefront).
Кнопка «Оформить подписку» → StoreKit External Purchase API → Safari → ЮKassa на сайте.
Бэкенд уже знает, активна ли подписка — приложение только проверяет после входа.
Android — entitlement не нужен; для РФ Google Play Billing и так не обязателен, редирект на ЮKassa проще.
Риски / нюансы
Entitlement не автоматический — Apple может отказать или долго рассматривать.
Форма для RU у некоторых разработчиков 500 error — нужен support case.
В EU при external link нельзя одновременно IAP в том же storefront (или по другим правилам — one or the other).
Юридически и по UX: checkout на вашем домене, не в WebView внутри аппа.
Коротко для заказчика:

«На iOS Apple даёт отдельное разрешение — External Purchase Link. С ним можно легально сделать кнопку “Оформить на сайте”, пользователь увидит предупреждение Apple и перейдёт на zerosmoker.ru с ЮKassa. Без этого разрешения так делать нельзя. На Android для России можно проще — сразу на сайт.»

Если нужно, могу расписать конкретный flow в приложении: какие экраны, какая кнопка, что убрать из текущего «Оформить подписку».
